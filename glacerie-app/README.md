# Glacerie — app iPhone (PWA)

Version installable sur iPhone du Gelato ERP (`erp-glacerie.html`) : menu tactile, plein écran, fonctionne hors-ligne.

## Installer sur l'iPhone
1. Ouvrir l'adresse de l'app dans **Safari**.
2. Bouton Partager → **Sur l'écran d'accueil** → Ajouter.

## Mise en ligne (GitHub Pages)
Réglages du dépôt → Pages → Source : **GitHub Actions**. Le workflow `.github/workflows/pages.yml` publie `glacerie-app/` à chaque push sur `main`.
Adresse : `https://villaartibypass-glitch.github.io/glace-glacerie/`

Les données sont enregistrées localement dans l'iPhone (localStorage).
